# Outcome model report (simulation)

Generated by `npm run fit-model -- 1500 500`. Training seeds `train-0…1499`, held-out seeds `holdout-0…499`.
The data is four smart table bots per hand (self-play), with one snapshot after every discard. That gives 69375 training and 23403 held-out snapshots.
Draw rate in training: 9.5%.

Caveats: the labels come from bot self-play, so the probabilities describe tables of smart bots. Humans
play differently. The model sees only public features: riichi, melds, discard counts, tsumogiri streaks
and the wall. It does not use tile-level reads (suji, dangerous tiles, dora visibility).
